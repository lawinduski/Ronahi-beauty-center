# Ronahi Beauty Center — Pro Edition

وێبسایتی ناوەندی جوانکاریی ڕۆناهی. Kurdish-first (RTL)، مۆدێرن، و ئامادەی مۆبایل.

## فایلەکان

| فایل | ئەرک |
|---|---|
| `index.html` | پێکهاتەی لاپەڕە |
| `styles.css` | هەموو دیزاینەکە (ڕەنگ، فۆنت، بۆکس، ڕیسپۆنسیڤ) |
| `app.js` | ئایکۆنی سۆشیال، گاڵێری، lightbox، فۆرمی ژوان |
| `config.js` | **هەموو لینک و زانیارییەکان لێرە دەگۆڕدرێن** |
| `api/book.js` | پشکنینی داواکاری، ژمارەی تایبەتی APT و ناردنی پارێزراو بۆ Telegram |
| `assets/gallery/` | وێنەی نموونەی کارەکان لێرە دابنێ |

## لینکی سۆشیال میدیا

لە `config.js` بەشی `social`، لینکی هەر ئەکاونتێک دابنێ:

```js
social: {
  snapchat:   { url: "https://snapchat.com/add/...",  handle: "@..." },
  instagram1: { url: "https://instagram.com/...",     handle: "@..." },
  instagram2: { url: "https://instagram.com/...",     handle: "@..." },
  facebook:   { url: "https://facebook.com/...",      handle: "" },
  tiktok:     { url: "https://tiktok.com/@...",       handle: "@..." }
}
```

ئەگەر `url` بەتاڵ بێت، ئایکۆنەکە دەچێتە سەر `socialHub` (LinkBio)، بۆیە هیچ لینکێک نایشکێت.
ئایکۆنی لۆکەیشن لە `maps` وەردەگرێت.

## وێنەی کارەکان

1. وێنەکان بخەرە ناو `assets/gallery/`
2. لە `config.js` بەشی `gallery`:

```js
gallery: [
  { src: "assets/gallery/work-1.jpg", title: "ناونیشان (ئارەزوومەندانە)", category: "face" },
  { src: "assets/gallery/work-2.jpg", title: "", category: "laser" }
]
```

`category` دەبێت یەکێک بێت لە: `face`, `laser`, `prp`, `hifu`, `other`. فلتەرەکان خۆکارانە دروست دەبن، و کلیک لە وێنە lightbox دەکاتەوە.
هەتا وێنە زیاد نەکەیت، شوێنی ئامادەکراو پیشان دەدرێت.

## زانیاریی ترەوە (ئارەزوومەندانە)

لە `config.js`: `phone`، `whatsapp`، `hours`، `address`، و `mapEmbed` (نەخشە لەناو ماڵپەڕ). هەر یەکێکیان بەتاڵ بێت، پیشان نادرێت.

## Vercel

لە Project Settings → Environment Variables:

- `TELEGRAM_BOT_TOKEN` = تۆکنی بۆتەکە
- `TELEGRAM_CHAT_ID` = چات ئایدیی خاوەنی ناوەند
- `RONAHI_BRANCH` = ناوی لق/شوێن (ئارەزوومەندانە؛ بنەڕەت: دهۆک، ڕێگای ڕەزا)

هیچکامیان نابێت لە HTML، CSS، JavaScript یان GitHub دابنرێت. وێبسایتەکە تەنیا وردەکاریی ژوان بۆ `/api/book` دەنێرێت و سێرڤەر نامەکە بۆ Telegram دەنێرێت.


## بەراوردی پێش و دوای

بەشی slider لە `config.js` بە `beforeAfter` ڕێکدەخرێت. وێنەی ڕاستەقینەی پێش و دوای بخەرە ناو `assets/gallery/` و ڕێڕەوەکان دابنێ. بەشەکە تا هەردوو وێنەکە دیاری نەکرێن، خۆی پیشان نادات؛ بەمەش هیچ وێنەی ساختە یان placeholder وەک ئەنجامی کڕیار پیشان نادرێت.

## ژوان و Telegram

فۆرمی ژوان و API پێشتر هەبوون. لە Vercel → Project Settings → Environment Variables ئەم دوو نهێنییە دابنێ و دوای گۆڕانکاری deploy بکە:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

دوای وەڵامی سەرکەوتووی Telegram، لاپەڕەی سەرکەوتن ژمارەی تایبەتی APT، زانیاریی ناردراوی کڕیار، شوێن و ڕۆژ/کات پیشان دەدات. داواکاری بە ڕوونی وەک «چاوەڕێی پشتڕاستکردنەوە» نیشان دەدرێت، نەک ژوانی پشتڕاستکراوە. دوگمەی Calendar فایلێکی `.ics` دروست دەکات. ئەگەر API یان Telegram هەڵە بدات، لاپەڕەی سەرکەوتن پیشان نادرێت و پەیامی هەڵە دەردەکەوێت. تۆکنی Telegram تەنیا لە server environment دابنێ؛ لە `config.js` یان فایلەکانی فرۆنت-ئێند مەیخە. تێبینی: لەم پرۆژەیەدا database ـی جیاواز نییە؛ سەرکەوتن واتە Telegram داواکارییەکەی وەرگرتووە و نامەکە لە Telegram دەمێنێتەوە.


### ژمارەی تایبەتی ژوان

هەر داواکارییەکی سەرکەوتوو ژمارەیەکی کورت وەک `APT-4821` وەردەگرێت. ژمارەکە بە شێوەی پارێزراوی هەڕەمەکی لە سێرڤەر دروست دەکرێت و تەنیا دوای وەرگرتنی داواکاری لەلایەن Telegram دەگەڕێندرێتەوە. چونکە database یان storage ـی بەردەوام بەکارناهێنین، ناتوانرێت گەرەنتی بدرێت کە ژمارەی ٤ ژمارەیی هەرگیز دووبارە نابێتەوە؛ بۆ گەرەنتیی تەواو پێویستە تۆمار و پشکنینی دووبارەبوونەوە هەبێت.

تێبینی: ئەم وەشانە database ـی نوێ زیاد ناکات؛ تۆماری داواکاری لە Telegram دەمێنێتەوە. بۆ گەرەنتیی تەواوی uniqueness بە پشکنینی تۆمارە پێشووەکان، پێویستە database یان storage ـێکی بەردەوام و پشکنینی unique constraint ڕێکبخرێت.
